## 1. 換個想法：猜一個答案，再慢慢修正

高斯消去法是**直接法**：做完固定步驟就得到答案。**迭代法**的想法完全不同：

1. 先**猜**一個答案 $`x^{(0)}`$（例如全部是 0）
2. 用某個規則，從 $`x^{(k)}`$ 算出「更好一點」的 $`x^{(k+1)}`$
3. 重複，直到夠準為止

**想一想：**

1. 高斯消去法需要約 $`n^3/3`$ 次乘除。如果 $`n = 100000`$，大約要多少次？
2. 在很多實際問題中（例如物理模擬），矩陣大部分元素都是 0，每一列只有少數幾個非零元素。這種情況下，迭代法每一步大約要多少運算？

## 2. Jacobi 法

### 2.1 從方程式出發

本部分統一使用以下例題（真正的解是 $`x = (1, 2, 3)`$，請先驗證）：

```math
\begin{cases}
4x_1 - x_2 = 2 \\
-x_1 + 4x_2 - x_3 = 4 \\
-x_2 + 4x_3 = 10
\end{cases}
```

把第 $`i`$ 條方程式「解出」$`x_i`$：

```math
x_1 = \frac{2 + x_2}{4},\qquad
x_2 = \frac{4 + x_1 + x_3}{4},\qquad
x_3 = \frac{10 + x_2}{4}
```

**Jacobi 法：** 右邊全部代入**上一輪**的值，算出這一輪的新值。

### 2.2 手算

從 $`x^{(0)} = (0, 0, 0)`$ 開始：

```math
x^{(1)} = \left( \frac{2 + 0}{4},\ \frac{4 + 0 + 0}{4},\ \frac{10 + 0}{4} \right) = (0.5,\ 1,\ 2.5)
```

**試試看：** 算出 $`x^{(2)}`$，以及 $`x^{(2)}`$ 的誤差 $`\lVert x^{(2)} - x \rVert_\infty`$。

<details>
<summary>答案</summary>

$`x^{(2)} = (0.75,\ 1.75,\ 2.75)`$，誤差 $`= 0.25`$

</details>

### 2.3 一般化

**想一想：**

1. 把第 $`i`$ 條方程式解出 $`x_i`$ 的一般公式，用 $`a[i][j]`$、$`b[i]`$、$`x[j]`$ 怎麼寫？
2. 這個公式什麼情況下不能用？（看看分母）
3. 算 $`x^{(k+1)}`$ 時要用**全部的舊值**。如果程式只用**一個陣列**存 $`x`$，邊算邊覆蓋，會發生什麼事？你需要幾個陣列？

## 3. Gauss-Seidel 法

### 3.1 改良的想法

在 Jacobi 法中，算 $`x_2`$ 時其實 $`x_1`$ 的新值已經算好了，為什麼不馬上用？

**Gauss-Seidel 法：** 每算出一個新值，**立刻**拿來用。

### 3.2 手算

從 $`x^{(0)} = (0, 0, 0)`$ 開始，第一輪：

- $`x_1 = (2 + 0) / 4 = 0.5`$
- $`x_2 = (4 + \mathbf{0.5} + 0) / 4 = ?`$（注意：用的是**剛算好的** $`x_1`$）
- $`x_3 = ?`$

**試試看：** 算完第一輪，再算第二輪，以及 $`x^{(2)}`$ 的誤差。

<details>
<summary>答案</summary>

- $`x^{(1)} = (0.5,\ 1.125,\ 2.78125)`$
- $`x^{(2)} = (0.78125,\ 1.890625,\ 2.97265625)`$，誤差 $`= 0.21875`$

</details>

**想一想：**

1. 比較兩種方法在第 2 輪的誤差，以及**每個分量**的誤差。哪一個分量差最多？為什麼？
2. Gauss-Seidel 法需要幾個陣列？
3. Jacobi 法裡，各分量的計算順序重要嗎？Gauss-Seidel 法呢？

## 4. SOR 法

### 4.1 想法：走得更大步（或更小步）

Gauss-Seidel 法從舊值 $`x_i^{\text{old}}`$ 走到新值 $`x_i^{\text{GS}}`$。如果我們發現每次都「走不夠遠」，何不多走一點？

```math
x_i^{\text{new}} = (1 - \omega)\, x_i^{\text{old}} + \omega\, x_i^{\text{GS}}
```

$`\omega`$ 稱為**鬆弛參數（relaxation parameter）**。

**想一想：**

1. $`\omega = 1`$ 時，SOR 等於哪一個方法？
2. $`\omega > 1`$（過鬆弛）和 $`\omega < 1`$（欠鬆弛）分別代表什麼？用「從舊值往新值走」的圖像解釋。

### 4.2 手算

用 $`\omega = 1.2`$，從 $`x^{(0)} = (0, 0, 0)`$ 開始：

- $`x_1^{\text{GS}} = (2 + 0)/4 = 0.5`$，所以 $`x_1 = (1 - 1.2) \times 0 + 1.2 \times 0.5 = 0.6`$
- 接下來算 $`x_2`$ 時，要用 $`x_1 = 0.6`$（不是 $`0.5`$）

**試試看：** 算完第一輪。

<details>
<summary>答案</summary>

$`x^{(1)} = (0.6,\ 1.38,\ 3.414)`$

</details>

**想一想：** $`x_3`$ 超過了真正的答案 3。這是好事還是壞事？

## 5. 什麼時候停下來？

迭代法不會「剛好」算到真正的答案，你必須決定什麼時候停。作業提到四種停止條件：

| 條件 | 意義 |
|------|------|
| $`\lVert b - Ax^{(k)} \rVert < tol_1`$ | 殘差夠小 |
| $`\lVert x^{(k)} - x^{(k-1)} \rVert < tol_2`$ | 兩次之間變化夠小（絕對） |
| $`\dfrac{\lVert x^{(k)} - x^{(k-1)} \rVert}{\lVert x^{(k)} \rVert} < tol_3`$ | 兩次之間變化夠小（相對） |
| $`k \ge tol_4`$ | 已經跑太多次了 |

**想一想：**

1. 哪一個條件**一定要有**？如果沒有它，在什麼情況下程式會出問題？
2. 哪一個條件計算成本最高？為什麼？
3. 相對變化在什麼情況下不適合用？（提示：如果真正的解 $`x = 0`$ 呢？）
4. 「兩次之間變化很小」一定代表「離真正答案很近」嗎？回想第二部分第 2 節。
5. 停下來之後，你的程式怎麼告訴使用者「是因為收斂而停」還是「是因為跑太多次而停」？

## 6. 什麼時候會收斂？

### 6.1 一個不收斂的例子

```math
\begin{cases}
x_1 + 2x_2 = 3 \\
3x_1 + x_2 = 4
\end{cases}
\qquad \text{真正的解：} (1, 1)
```

**試試看：** 用 Jacobi 法從 $`(0, 0)`$ 開始算 3 輪。

<details>
<summary>答案</summary>

$`(3, 4) \to (-5, -5) \to (13, 19)`$，越來越遠，**發散**了。

</details>

**想一想：**

1. 這個矩陣是嚴格對角優勢嗎？
2. 把兩條方程式**對調順序**，再用 Jacobi 法試試看。發生什麼事？為什麼？

### 6.2 迭代矩陣與譜半徑

三種方法都可以寫成

```math
x^{(k+1)} = T\, x^{(k)} + c
```

其中 $`T`$ 稱為**迭代矩陣**。誤差 $`e^{(k)} = x^{(k)} - x`$ 滿足 $`e^{(k+1)} = T\, e^{(k)}`$。

重要定理：**迭代收斂 ⇔ $`T`$ 的譜半徑 $`\rho(T) < 1`$**，其中 $`\rho(T)`$ 是 $`T`$ 的所有特徵值中絕對值最大的那一個。$`\rho(T)`$ 越小，收斂越快。

**試試看：** 寫出第 2 節例題 Jacobi 法的迭代矩陣 $`T_J`$。

<details>
<summary>提示</summary>

從 2.1 節的三個式子看，$`x_1^{(k+1)}`$ 依賴 $`x_2^{(k)}`$ 的係數是多少？依此類推。

</details>

<details>
<summary>答案</summary>

```math
T_J = \begin{bmatrix} 0 & 1/4 & 0 \\ 1/4 & 0 & 1/4 \\ 0 & 1/4 & 0 \end{bmatrix}
```

</details>

### 6.3 用 Gershgorin 定理估計譜半徑

特徵值不好算，但 **Gershgorin 圓盤定理** 可以給我們一個範圍：

> 矩陣 $`T`$ 的每一個特徵值，都落在某一個圓盤裡。第 $`i`$ 個圓盤的圓心是 $`t_{ii}`$，半徑是第 $`i`$ 列**其他元素絕對值的總和**。

**試試看：** 對上面的 $`T_J`$ 畫出三個圓盤，估計 $`\rho(T_J)`$ 的上界。Jacobi 法一定收斂嗎？

<details>
<summary>答案</summary>

三個圓盤的圓心都是 0，半徑分別是 $`1/4`$、$`1/2`$、$`1/4`$。所以所有特徵值的絕對值 $`\le 1/2`$，$`\rho(T_J) \le 1/2 < 1`$，一定收斂。

</details>

**想一想：**

1. 對一般的嚴格對角優勢矩陣 $`A`$，$`T_J`$ 第 $`i`$ 列的 Gershgorin 半徑是什麼？用這個結論證明：**嚴格對角優勢 ⇒ Jacobi 法收斂**。
2. 反過來成立嗎？不是對角優勢的矩陣，Jacobi 法一定發散嗎？試著找一個反例。
3. 用 6.1 節的發散例子，算出 $`T_J`$ 的 Gershgorin 圓盤。定理在這裡能告訴你什麼？不能告訴你什麼？

### 6.4 SOR 的 $`\omega`$ 範圍

**Kahan 定理：** 對 SOR 法，$`\rho(T_\omega) \ge |\omega - 1|`$。

**想一想：**

1. 根據這個定理，$`\omega`$ 必須在什麼範圍內 SOR 才**有可能**收斂？
2. 作業要你測試 $`\omega = 2.2`$。在動手之前，先預測結果。

## 7. 設計實驗

### 7.1 比較三種方法

作業要求：**同一個系統、同一個初始猜測**，比較 Jacobi、Gauss-Seidel、SOR 的迭代次數與誤差衰減。

**建議做法：**

1. 自己設計一個嚴格對角優勢系統（先決定答案，再算 $`b`$）
2. 每一輪迭代都輸出：迭代次數 $`k`$、誤差範數 $`\lVert x^{(k)} - x \rVert`$
3. 把輸出存成 CSV 檔，用試算表（Excel、Google 試算表）或繪圖工具畫圖
4. **縱軸使用對數刻度**

**想一想：**

1. 在對數刻度下，誤差曲線長什麼樣子？如果是直線，代表什麼？
2. 直線的斜率和 $`\rho(T)`$ 有什麼關係？（提示：$`\lVert e^{(k)} \rVert \approx \rho^k \lVert e^{(0)} \rVert`$，兩邊取對數）

### 7.2 尋找最佳 $`\omega`$

- 先用作業指定的 $`\omega = 0.5, 1.0, 1.2, 1.5, 1.8`$，記錄每個 $`\omega`$ 達到同樣停止條件所需的迭代次數
- 找出最好的區間後，再**加密**取點（例如間隔 0.05），畫出「迭代次數 vs. $`\omega`$」的圖
- 最後測試 $`\omega = 2.2`$，和 6.4 節的預測比較

**想一想：** 最佳的 $`\omega`$ 會隨著矩陣不同而改變嗎？換一個系統試試看。

### 7.3 延伸：不是對角優勢的矩陣、條件數

- 拿一個**不是**對角優勢的矩陣，看看三種方法會不會收斂
- 拿一個條件數很大的矩陣（例如第一部分第 12.2 節的希爾伯特矩陣），觀察迭代法要跑多久。停止條件「殘差夠小」可靠嗎？（回想第二部分第 3 節）

## 8. 用來驗證程式的參考數據

用第 2 節的例題測試你的程式。設定如下：

- 初始猜測 $`x^{(0)} = (0, 0, 0)`$
- 停止條件：$`\lVert x^{(k)} - x^{(k-1)} \rVert_\infty < 10^{-6}`$
- 最多 1000 次

| 方法 | 達到停止條件時的 $`k`$ |
|------|----------------|
| Jacobi | 15 |
| Gauss-Seidel | 9 |
| SOR，$`\omega = 0.5`$ | 33 |
| SOR，$`\omega = 1.2`$ | 12 |
| SOR，$`\omega = 1.5`$ | 24 |
| SOR，$`\omega = 1.8`$ | 71 |
| SOR，$`\omega = 2.2`$ | 不收斂 |

如果你的數字差 1，檢查一下你的 $`k`$ 是從 0 還是從 1 開始數。差很多的話，先用第 2～4 節的手算結果，逐輪比對前兩輪的數值。

**注意：** 這只是用來檢查程式是否正確的參考數據。作業要你用**自己設計的系統**做實驗，而在這個例題中表現最好的 $`\omega`$，在別的系統上不一定最好。
